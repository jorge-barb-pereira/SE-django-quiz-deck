# Historical source archive

`quiz/` contains the final February 2025 assessment-card project. `tutorials/` contains earlier polls, movies and DRF learning exercises from January 2025.

These are sanitized historical references, not alternate application entry points. Embedded secret/email settings were removed; institution-specific email construction uses `example.invalid`. The manifest records source/published hashes and every transformation. Original comments and source structure remain in their historical language. No original databases or course documents are included.

Some archived code is incomplete or unsafe to run as an exposed service; see `docs/REVIEW.md`. The runnable maintained app is at the repository root. Do not add this archive to INSTALLED_APPS or execute the historical settings.
